# Mise en place

Ce que j'ai fait pour monter le projet :

- npm init
- npm install express cors dotenv
- les dossiers routes, controllers et middleware
- server.js pour lancer, app.js pour la config
- un .gitignore et un .env.example

Pour lancer : npm install puis npm start.
